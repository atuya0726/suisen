## 狙い（ロングテールの軸）

1. **人物名**: 「〇〇 おすすめ本」「〇〇 愛読書」。名前で検索される人（作家、芸能、スポーツ選手、著名な経営者・学者）を増やす。
2. **所属**: 「〇〇大学 推薦図書」。大学ごとに教員の推薦をまとめる（所属別ページは未実装。データの `affiliation` だけ先に入れている）。
3. **本**: 複数の人が薦めた本。同じ本を挙げる人が増えるほど、本ページとランキングが育つ。

## 収集の優先順位

毎日の収集は、上から順に、その日の上限まで進める。週次の振り返りで見直す。

1. **著名人の新着**: 下の「継続して見る一覧」の連載に、新しい回が出ていないかを見る。
2. **著名人の候補**: 台帳（`data/research/checked-urls.json`）で `result` が `candidate` の記事のうち、著名人のもの。
3. **新しい連載・企画の発見**: 著名人が本を薦める無料の連載を、まだ調べていない媒体から探す（雑誌の Web 版、出版社の特集、新聞の無料連載など）。見つけた一覧は台帳に `index` として残す。
4. **大学の教員**: 1つの大学は1日10人まで。大学が偏らないようにする。北海道大学は一覧ページから機械的に取れる（新着の確認だけでよい）。
5. **本人のサイト・note・研究者プロフィール**: 著名人や研究者が、自分のサイトに「おすすめ本」「推薦図書」「読書案内」を載せているページ。1ページで多くの本が取れ、本人の発信なので紐付けの誤りが少ない。探し方は下の「新しい収集先の探し方」。大学は1日10人までの上限に含める。
6. **選書家・書店主の選書記事**: 実名とプロフィールのある個人が、自分で読んだ本を薦めている記事（例: Chapters Blog）。定番の本が多く、複数人が薦めた本を増やすのに効く。人物は `noPage: true`・属性「選書家」で登録し、個別ページは作らない（ページがその人の選書リストの再現になるため）。匿名の編集部の記事、他人の愛読書をまとめた記事、アフィリエイト目的のまとめ記事は対象外。1日2記事まで。

## 新しい収集先の探し方

人を決めて「〇〇 おすすめ本」で探すと、第三者のまとめ記事ばかり出る。**本人や大学が見出しに使う言葉**で探し、推薦を続けて公開している人・同じ型のページを持つサイトを見つけて、そこを掘る（2026-11-16 にユーザーから提供された調査を元に追加）。

- **検索の型**: `site:ac.jp "おすすめの本" 教授`、`site:ac.jp "推薦図書" 教授`、`site:ac.jp "読書案内" 教授`、`site:ac.jp "学生に読んでほしい"`、`site:note.com "今年読んでよかった本"`、`"私のおすすめ本" 公式サイト`、`"推薦図書" 研究室`。
- **同じ型の横展開**: 大学の教員プロフィールに「おすすめの本」「推薦図書」の欄が1人見つかったら、同じ学部・学科の教員一覧を見て、同じ欄を持つ教員を拾う（北海道大学 文学研究院、日本大学文理学部 国文学科、東京大学 科学史・科学哲学研究室の「読書案内」がこの型）。
- **年次の記事**: 「今年のおすすめ本」を毎年書く人（為末大の note など）は、継続して見る一覧に足す。
- **取得の決まり**: 初めてのサイトは robots.txt を見る。`User-agent: *` で対象のパスが禁止されているサイト、Claude・anthropic の名前で拒否しているサイト（HONZ など）は取得しない。note は記事ページの HTML だけを取り、API・検索・アーカイブのパスは使わない。続けて取るときは1秒以上空ける。
- **数えないもの**: 読書案内の中で「勧められない」と書かれた本、参考文献として並んでいるだけの本、1冊ずつ論じる長期の書評（千夜千冊、土井英司のビジネスブックマラソンなど。薦めていると明言した回だけを選ぶ手段ができるまで保留）。

## YouTube からの収集

`python3 scripts/fetch-youtube.py` で、チャンネルの動画のタイトル・公開日・概要欄と、概要欄の Amazon リンクから取れる ISBN を出せる（API キーはキーチェーンの `YOUTUBE_API_KEY`。1日 10,000 単位。チャンネルを名前で探す `find` は1回 100 単位と重い）。

- 対象は、著名人本人のチャンネルで、概要欄に「紹介した本」を書いているもの。本の要約だけをする匿名のチャンネルは対象外。
- **ほぼ全部の動画に同じ ISBN が入っていたら、それは自著か定型の宣伝**。数えて除く。
- 「動画内で紹介した書籍」のような見出しの下にある本だけを採る。スポンサーの本、参考文献の列挙は採らない。
- 再放送や切り抜きの動画に同じ本が出るので、本ごとに、通常の動画のうちいちばん古いものを出典にする。
- 洋書（ISBN が 9784 で始まらないもの）は除く。Kindle 版のリンク（B0…）からは ISBN が取れない。
